# Bibliografía del taller

Copias de lectura de los textos de la sección «Bibliografía por módulos» del [README principal](../README.md). Cada módulo tiene dos subcarpetas:

- `sugerida/`: lecturas sugeridas, que orientan la discusión de cada jornada.
- `ampliatoria/`: lecturas ampliatorias, para profundizar.

| Carpeta | Módulo |
| --- | --- |
| `A/` | Módulo 1. Layout, materialidad y segmentación |
| `B/` | Módulo 2. OCR, errores y crítica de fuentes digitalizadas |
| `C/` | Módulo 3. EntropIA Lite, desarrollo y crítica de herramientas |
| `D/` | Módulo 4. RAG, agentes y consulta asistida |

Los archivos se nombran `Autoría_Año_Título-abreviado.pdf`. La columna **Versión** indica qué se guardó: *editorial* (versión publicada), *autor* (preprint o manuscrito aceptado depositado por la autoría), *preprint* (arXiv) o *web* (página impresa a PDF desde el navegador). Para citar, usar la referencia completa de cada tabla, no el nombre del archivo.

> **Uso educativo.** Las copias se facilitan exclusivamente para la lectura y el trabajo dentro del taller. Los archivos marcados con © tienen todos los derechos reservados por la editorial, o son traducciones no oficiales de esas obras.
